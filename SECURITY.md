# Reporting security vulnerabilities

For a suspected vulnerability in Morfira CMS, use **Report a vulnerability** on the repository's [Security Advisories page](https://github.com/morfira-dev/morfira-cms/security/advisories) when the private form is available. If the button is missing, keep the report private until a confidential channel is available. Public issues and pull requests are visible to everyone.

Include the affected release tag or commit, the affected component, the potential impact, and enough detail for maintainers to investigate using a disposable installation. Use synthetic data and redact credentials, session identifiers, personal data and private URLs.

Use the [bug report form](https://github.com/morfira-dev/morfira-cms/issues/new?template=bug.yml) for ordinary product defects.
